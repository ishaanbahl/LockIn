Lok is a productivity app that holds you accountable by blocking distracting apps, Instagram, TikTok, YouTube, and more, until your task list is complete.

No subscriptions. No fluff. Just your tasks and the focus to finish them.

How it works:  

1. Add your tasks for the day. 
2. Choose which apps to block. 
3. Lok will block all the distracting apps so you don't randomly need to scroll. Need to actually do something important? You can unblock each app for 5 minutes.
5. If you need tasks done by a certain time, Lok will send you reminders ahead of time.
4. Once your tasks are done, all apps will open fully. You're done for the day, feel free to doom scroll if you want to. 

Features:  
• Block any app until tasks are done. 
• Task reminders and a daily 7 AM morning summary. 
• Color-code and organize your tasks.  
• Indent tasks to create subtasks.  
• Set due times with 1-hour and 5-minute reminders.  
• Clean, minimal design built for focus.
